<h1>Introduction</h1>
<p>
This is an e-commerce website built with Django. Although it's mainly a practice project and part of my portfolio, I've tried to make it as close to a real-world e-commerce website as possible.

The project includes several features, such as authentication, account management, a blog, product pages, an About Us section, a Contact Us page, a custom admin panel, and more.

I've also tried to make certain sections, like the About Us page and advertisements, fully dynamic, so they can be easily managed and updated through the admin panel.
</p>


<h1>Setup</h1>
<p>
First, clone the project from GitHub, then run Docker Compose using the following command.

Note: Internet restrictions may cause errors when downloading packages from PyPI. If you run into any issues, try using a VPN or another way to bypass these restrictions.

1- Clone project:
    ``` 
    git clone https://github.com/AmiraliTanabian/Django_Shop 
    ```
2- Run docker compose:
    ```
    docker compose up
    (If use linux dont forget sudo)
    ```

</p>

<h2>Frontend</h2>
This project uses a free, pre-built template for its frontend. The main goal was to develop the backend using Django, not to build the frontend from scratch.
